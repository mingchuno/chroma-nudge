# Chroma Nudge

A browser-only photo harmony reference tool for photographers preparing a color grade.

Open a local photo, place and name color samples, inspect the HSL wheel, fit or choose a harmony, and export reference colors. The original photo stays unchanged. The user decides the mood and protects meaningful colors through an anchor.

React and TypeScript, built with Vite. No backend, accounts, analytics, remote assets, or persistent photo storage. The standalone HTML works directly from disk. JPEG, PNG, WebP, and AVIF inputs; at most 16 samples. SVG and JSON exports omit the image.
